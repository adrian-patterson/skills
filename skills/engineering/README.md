# engineering

Skills for writing, reviewing, and shipping code.

## Model-invoked

- [context-fix](./context-fix/SKILL.md): Audit a repository's agent context against the code it describes, then repair the defects the repository can prove.
- [pr-description](./pr-description/SKILL.md): Write the pull request description for the current branch as markdown to paste into GitHub.
- [triage-gh-pr-comments](./triage-gh-pr-comments/SKILL.md): Triage the review comments on the current branch's GitHub PR, report the verdicts, and fix the approved ones. Needs the GitHub MCP server.
